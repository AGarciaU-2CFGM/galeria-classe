# Galeria de la classe

Web amb una fitxa de cada alumne del grup, cadascuna amb un enllaç a la seva pàgina personal.

Projecte organitzat per en Pau Pino.

## Com hi pots afegir la teva fitxa

1. Busca la teva issue a la pestanya **Issues** i assigna-te-la.
2. Fes un **fork** d'aquest repositori i clona el teu fork.
3. Crea una branca `fitxa-nomcognom` i canvia-hi.
4. Copia el fitxer `alumnes/paupino.html` amb el nom `alumnes/nomcognom.html` i canvia-hi les dades.
5. Fes commit i puja la branca al teu fork.
6. Obre una Pull Request cap a aquest repositori amb `Closes #N` a la descripció.

**Important:** no modifiquis cap altre fitxer. Cada alumne només crea el seu fitxer dins de `alumnes/`.

La galeria troba les fitxes automàticament: quan s'accepta la teva PR, la teva fitxa hi apareix sola (pot tardar un parell de minuts).
